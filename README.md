# MiCT Team Pre-Survey 🇺🇦🇰🇷

**2026 WFK IT Program** | Pre-Survey Web Form  
Built by MiCT Team (Gaeun · Dayoung · Nayoung · JeongA)

## About

A bilingual survey web page for Ukrainian students participating in the 2026 WFK IT Program.  
Supports **English ↔ Ukrainian** language toggle and is fully responsive across mobile and desktop.

## Features

- 🌐 English / Ukrainian bilingual toggle
- 📱 Responsive design (iPhone, Android, Desktop)
- 🎨 Custom design based on MiCT Team Figma mockup
- 📋 Two sections: Programming Class + Korean Cultural Exchange
- ✅ Connects to Google Forms on submission
